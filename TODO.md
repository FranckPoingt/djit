# DJ-IT roadmap

The current alpha implements import, triage, audio preview, metadata cleanup,
background analysis, saved views, playlists, discovery graph, and folder extraction.

Before a public release, follow [docs/RELEASING.md](docs/RELEASING.md).

Future work, not prerequisites for publishing source:

- Engine DJ integration (the current API entry point is a placeholder).
- Validated Intel Mac, Windows, and Linux desktop packaging.
- Apple Developer ID signing and notarization for downloadable Mac releases.
- Broader real-library performance and analysis-accuracy testing.
- Local API origin/host protection and desktop session authentication.
