# Security

DJ-IT is an alpha application intended for one trusted user on a local machine.
Its local API can read music and write exports and has no user authentication.
Never bind or proxy it to a public network. Only import files you trust.

Do not post vulnerabilities, personal library databases, full diagnostic archives,
or credentials in public issues. Use GitHub's private vulnerability reporting at
https://github.com/FranckPoingt/djit/security/advisories/new when enabled. If private
reporting is unavailable, ask the maintainer for a private contact channel without
including vulnerability details.

Only the latest source revision is supported during alpha. There is no guaranteed
response time or automatic security-update channel.
